# TV Reader

A free screen reader for Android TV / Google TV, in early public (beta) testing.

TV Reader reads the text that apps expose to accessibility services - menus, buttons and other items - and speaks it aloud. Features include review-style navigation, a talking clock, and screen help. You can choose your own TTS engine and voices, including mixed Hindi-English reading.

Privacy: the app has no Internet permission and keeps no history of your screen text. System TTS voices may use the network on their own.

## Install

Download the latest APK from Releases, open it on your TV, and enable the accessibility service when asked. Requires Android 11 or newer. Builds are intended to install in place over older versions (same package and signing key); do not uninstall or clear data if you want to keep settings.
